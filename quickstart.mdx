Use this path when you are setting up or orienting around the main Bounty app.

## Prerequisites

- A Bounty account.
- Access to the organization you want to work in.
- Connected marketing or business data sources.

## 1. Open Bounty

Sign in to the Bounty app at `app.bountygrowth.com`.

## 2. Confirm Your Workspace

Check that you are in the right organization before reviewing performance, running agents, or creating actions.

## 3. Review Connected Data

Use Connections and Settings to confirm that the data sources and organization context are ready for analysis.

To authorize Google resources, follow the [Google Ads](/integrations/google-ads) or [Google Analytics](/integrations/google-analytics) guide. These native flows currently store authorization and selected resources; reporting still depends on the data path activated for the organization. For the broader setup model, see [Data hierarchy](/data-hierarchy).

## 4. Inspect Performance

Start with the analytics home, then drill into Metrics, Driver Tree, Campaigns, Ads, or Chat depending on the question.

Useful first questions:

- Which metrics moved this week?
- Which campaigns are driving spend, conversions, or CAC changes?
- Are any ads or creatives showing fatigue?
- Which actions are ready to plan, run, or analyze?
- Which agents are configured for this workspace?

## Agent Workflows

To connect an MCP client, open [Bounty Settings](https://app.bountygrowth.com/settings), copy the MCP URL, and follow the instructions there. See the [MCP server guide](/mcp/overview) for available tools and example workflows.
