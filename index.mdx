Bounty Docs is the public documentation site for Bounty. Bounty is the web app for marketing analytics and growth operations. It helps teams connect marketing data, define metrics, inspect paid performance, analyze campaigns, manage growth actions, run agents, and ask questions through AI chat.

The CLI and MCP server are companion surfaces for terminal and agent workflows. The main product experience is the Bounty app at `app.bountygrowth.com`.

## Product Areas

- Analytics home for key metrics, trends, and growth levers.
- Metrics and driver trees for modeling business performance.
- Campaign and ad views for paid performance across connected platforms.
- Actions for planning, tracking, and analyzing growth work.
- Agents for repeatable analysis and post-sync workflows.
- Chat for exploring data and asking follow-up questions.
- Connections and settings for organization data setup.
- Data hierarchy for understanding connectors, connections, tables, data sources, and fields.
- MCP server access for read-only agent workflows through OAuth.

## Start Here

Use the Bounty app quickstart when you are onboarding a team or setting up a workspace.

Use the CLI quickstart when you want Claude Code, Codex, another AI coding agent, or a terminal workflow to query Bounty with normal user permissions.

## Public Surfaces

- The public Bounty landing page at [`www.bountygrowth.com`](https://www.bountygrowth.com/).
- The Bounty app, which is the primary product experience.
- [`bounty-cli`](https://github.com/bounty-growth/cli), the open-source authenticated command line interface for marketing operations.
- The Bounty MCP server, a read-only app-hosted endpoint for OAuth-aware MCP clients.
- Bounty agent skills, which teach Claude Code, Codex, and other AI coding agents how to use the CLI safely and consistently.
