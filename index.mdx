# Bounty

Bounty is the web app for marketing analytics and growth operations. It helps teams connect marketing data, define metrics, inspect paid performance, analyze campaigns, manage growth actions, run agents, and ask questions through AI chat.

The CLI is a companion surface for terminal and agent workflows. The main product experience is the Bounty app at `app.bountygrowth.com`.

## Product Areas

- Analytics home for key metrics, trends, and growth levers.
- Metrics and driver trees for modeling business performance.
- Campaign and ad views for paid performance across connected platforms.
- Actions for planning, tracking, and analyzing growth work.
- Agents for repeatable analysis and post-sync workflows.
- Chat for exploring data and asking follow-up questions.
- Connections and settings for organization data setup.

## Start Here

Use the Bounty app quickstart when you are onboarding a team or setting up a workspace.

Use the CLI quickstart when you want an AI coding agent or terminal workflow to query Bounty with normal user permissions.

## Public Surfaces

- The Bounty app, which is the primary product experience.
- `bounty-cli`, the authenticated command line interface for marketing operations.
- Bounty agent skills, which teach AI coding agents how to use the CLI safely and consistently.
