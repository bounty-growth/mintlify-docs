# Bounty Docs

Public documentation for the Bounty app, marketing operations CLI, MCP server, and AI agent skills.

Bounty helps teams connect marketing data, inspect performance, manage growth actions, run agents, and use terminal-safe CLI workflows with normal user permissions.

## Styling

`docs.json` and `custom.css` use the Bounty monorepo's UI foundations: Modern Gothic typography, sand shell, white surfaces, orange accents, and 8px corners. The docs use a light appearance to match the product.

The fonts come from `bounty/packages/ui/fonts/modern-gothic`, and the unmodified logo comes from `bounty/packages/ui/bounty-logo/bounty-logo.svg`. `favicon.png` and the ICO fallback are exact copies of `bounty/src/app/icon.png` and `bounty/src/app/favicon.ico`. Keep these assets and CSS tokens aligned with their monorepo sources when the brand changes.
