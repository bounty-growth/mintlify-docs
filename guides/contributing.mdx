# Contributing

This repository contains public Bounty documentation. It is not the Bounty app, CLI source, infrastructure, or an extension point for product code.

Pull requests should only change public docs content or audited public agent skill copy. Do not contribute application code, CLI implementation code, API routes, data pipelines, deployment configuration, private skills, internal scripts, or any other product source code here.

Keep implementation details, private infrastructure names, customer data, and internal runbooks out of this repo.

## Accepted Changes

- Public docs corrections and clarifications.
- Navigation, formatting, and broken-link fixes.
- Audited public agent skill documentation.
- Public-safe examples that use documented Bounty app or CLI behavior.

## Out Of Scope

- Bounty app code or UI implementation.
- `bounty-cli` package implementation.
- API route, auth, database, warehouse, or infrastructure changes.
- Private repository paths, internal scripts, or deployment details.
- Customer data, internal test data, or unreleased product plans.

## Local Preview

Install the Mintlify CLI:

```bash
npm i -g mint
```

Run a local preview from the repository root:

```bash
mint dev
```

## Validate Before Publishing

```bash
mint validate
mint broken-links
```

After the docs site is public, check agent readiness:

```bash
mint score https://docs.bountygrowth.com
```

## Public Content Checklist

Before opening a docs pull request, check that it does not include:

- Private source paths or package internals.
- API route implementation details.
- Database, warehouse, or infrastructure credentials.
- Local environment file names or values.
- Internal customer names, test data, or unreleased product plans.
- Product code, generated code, build scripts, or deployment configuration.

## Agent Skills

Mintlify serves custom skills from `.mintlify/skills/`. Each skill lives in its own folder with a `SKILL.md` file.

Do not symlink skills from private repositories into this repo. Copy only audited, public-safe skill files, and only when the skill content is meant to be public.
